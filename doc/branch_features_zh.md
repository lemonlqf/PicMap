# PicMap 分支功能清单（picmap-go）

> 分支：`picmap-go`　基线：`main`（旧的 Electron + Express + Leaflet 版本）
> 说明：本分支相对 `main` 共 62 个提交，主体是 **Go + Wails 重写**，并新增了以下功能。
> 已剔除旧版 `main` 就已具备的功能（图片上传与分组、GPX 轨迹基础与统计、多用户、备份基础与覆盖/合并模式、时间轴、国际化、HEIC/HEIF 与 RAW 系列、标记聚合、纯图模式等），此处不再重复列出。

---

## 一、架构 / 技术栈迁移（重构）

- Electron + Express → **Go + Wails v2**（前后端通过绑定通信，无 HTTP 层）
- Leaflet + leaflet-gpx + leaflet.markercluster → **MapLibre GL + Supercluster**（WebGL 矢量渲染）
- 图片选择 / 导入 / EXIF / 预览 / 缩略图**下沉到 Go 端**
- 图片、视频**分批解析 + 事件推送**（`images-parsed` / `images-progress` / `images-done`，视频同理）
- 外部工具随程序分发：**ImageMagick（HEIC 转码）、libraw（RAW 解码）、ffmpeg（视频探测 / 取帧）**
- 新增**本地媒体流服务**：仅监听 `127.0.0.1` 随机端口，支持 HTTP Range
  - `GET /video?userId=&videoId=`
  - `GET /image?userId=&imageId=&kind=thumb|marker|full`
- 一键打包脚本 `build.ps1`：生成图标 → `wails build` → 组装自包含交付目录 `dist/`（`picmap.exe` + `tools/`）

## 二、新增功能

### 1. 轨迹视频

- **视频导入**：自动探测时长与拍摄时间（`creation_time` 优先，文件名时间兜底）与内嵌 GPS
- **内嵌 GPS 独立视频**：自带 GPS 的视频作为独立标记显示在地图上
- **时间对齐关联**：通过「对齐视频」弹窗把视频以色带形式拖拽 / 输入到轨迹时间线
  - 支持**绝对对齐**（按视频绝对起止时刻）与**相对对齐**（全部早于轨迹起点时按间隔排布）
- **轨迹视频节点**：轨迹线上按采样与距离抽稀生成视频节点，点击弹出播放窗
- **视频播放**：基于 **video.js** 的自定义控制栏（播放 / 暂停、音量、进度、全屏、键盘快捷键）
- **流式播放**：优先走本地 HTTP 流（支持 Range，边下边播），不可用时回退分块读取
- **视频封面**：自动提取第一帧作为标记 / 列表封面
- **全景视频**：手动切换为全景视频，等距柱状投影沉浸式播放
- **视频分组与删除**：视频可加入分组、批量删除

### 2. 全景 360

- **全景图片**：自动识别球面 / 柱形（XMP GPano 优先，宽高比兜底）
- **沉浸式查看器**：投影切换（小星球 / 普通全景）、全屏、原图加载
- **手动切换**：右键设置 / 取消全景
- **全景视频**：支持全景视频播放

### 3. 框选与批量操作

- **框选**：`Ctrl`（macOS `Cmd`）+ 左键拖拽框选；按住修饰键为追加选中，否则替换；`Esc` 取消
- **选中预览**：工具栏显示已选中节点数量
- **批量操作**：批量删除、批量加入分组、清空选中
- 分组节点不参与框选；聚合点自动展开为其包含的全部图片 / 视频

### 4. 地图交互增强（MapLibre）

- **聚合过渡动画**：单点飞向 / 飞离聚合中心的合并 / 分裂动画；cluster 之间分裂 / 合并飞行动画
- **蜘蛛网展开（spiderfy）**：同位置多节点展开，带展开 / 合并动画
- **俯仰角调节**：滑块调节并双向同步（与时间轴同级展示，随纯净模式淡入淡出）

### 5. 瓦片叠加层

- 可为某张底图配置额外叠加层（如卫星底图叠加路网标注），支持多条，且不遮挡轨迹线

### 6. 存储目录可配置

- 数据目录与备份目录可在「设置」中修改
- 记录在用户主目录 `.picmap-config.json`，跨启动生效

### 7. 图标库（自定义图标）

- 全局图标库，支持上传 / 删除自定义图标，用于用户头像与轨迹起终点图标

### 8. 数据备份与恢复增强

- **进度条 + 中途取消**：备份过程可视化，可随时取消
- **恢复进度**：恢复过程显示进度
- **原子恢复**：覆盖模式先解压校验，成功后再原子替换，失败保留原数据
- **合并去重**：合并模式按 ID 去重追加
- 体积超过 500MB 时提示

### 9. 用户统计扩展

- 用户悬浮卡与设置页在原有「图片 / 分组」基础上，新增 **视频数量** 与 **轨迹数量**

### 10. GPX 时区设置

- GPX 时间戳无时区时按所选时区解释（内置常用时区，覆盖 UTC-12:00 ~ UTC+14:00）

### 11. 图片格式扩展

- 新增 **TIFF（`.tif` / `.tiff`）** 输入支持

## 三、性能与体验

- marker 专用 **120px 小图** + `moveend` 防抖 + in-flight 去重
- 缩略图 **LRU 缓存**（marker 2000 / large 300 / 视频封面 500 条），删除用户 / 图片时同步清理
- 视频封面**三级缓存**：内存 → 落盘 → ffmpeg 提取
- 图片解析**逐张渐进展示**，避免同帧大量渲染
- `ffmpeg` / `ffprobe` 经 **UPX 压缩**（各约 98MB → 26MB）
- 备份改为 `zip.Store` + 1MB 分块流式写入，避免大文件 OOM

## 四、主要修复 / 兼容

- 图片文件命名补 `PM` 前缀，与 Node 版磁盘格式兼容
- schema 字段名 `verison` → `version`，与磁盘数据一致
- 备份 ZIP 条目路径统一正斜杠，兼容 Node 版 archiver 输出
- 聚合索引随时间筛选重建，cluster 数量与成员跟随筛选
- 切换用户后刷新地图数据
- HEIC / HEIF EXIF 解析先转 JPEG；RAW 转换命名匹配 dcraw 输出
- 聚合 / 离散动画仅在缩放时触发，平移直接显示

## 五、技术栈

### 前端

- Vue 3 + TypeScript + Vite
- MapLibre GL、Photo Sphere Viewer、video.js
- Element Plus、Pinia、vue-i18n、Supercluster、lodash-es

### 后端

- Go + Wails v2（无 HTTP 服务）
- imaging / golang.org/x/image（解码、缩放、缩略图）
- goexif（EXIF 解析）、archive/zip（备份）
- 本地 HTTP 媒体流服务（127.0.0.1，支持 Range）
- 外部工具：ImageMagick、libraw、ffmpeg（随程序分发至 `dist/tools/`）
