# PicMap 项目功能介绍

---

> 一个基于 Vue3 前端 + Go(Wails) 后端的本地图片地图管理应用，让你的照片在地图上展示！

---

## 核心特性

| 特性 | 说明 |
|------|------|
| 🔒 本地存储 | 所有数据保存在本地，无隐私泄露风险 |
| 🗺️ 地图展示 | 支持多种地图瓦片与叠加层，直观展示照片位置 |
| 📤 批量上传 | 一次选择多张图片，支持 HEIC/HEIF/RAW 格式 |
| 🏷️ 图片分组 | 创建分组、筛选、批量操作 |
| 🛤️ GPX 轨迹 | 上传、展示和管理 GPX 轨迹文件 |
| 🎬 轨迹视频 | 视频按时间对齐关联到轨迹，支持边下边播与全景视频 |
| 📍 全景图片/视频 | 支持球面/柱形全景的沉浸式查看 |
| ⏱️ 时间轴 | 按拍摄时间筛选地图上的图片/视频 |
| 👥 多用户 | 支持多用户系统，数据相互隔离 |
| 💾 数据备份 | 支持备份、导入、恢复，安全可靠 |
| 🌍 国际化 | 支持中文、英文等多种语言 |

## 功能模块

### 1. 图片上传与管理

- **批量上传**：支持一次性选择多张图片上传，上传前可预览名称、GPS 坐标等信息
- **自动 GPS 解析**：自动从图片 EXIF 信息中提取 GPS 坐标并定位
- **手动定位**：支持为没有 GPS 信息的图片手动设置位置（点击地图选择坐标）
- **图片删除**：支持删除单张或多张图片
- **图片描述**：支持为图片添加描述信息
- **全景图片**：自动识别球面/柱形全景（优先读 XMP GPano 元数据，宽高比兜底），可沉浸式查看，也支持右键手动切换

### 2. 地图展示

- **多种地图瓦片**：内置高德卫星、高德矢量、高德 3D，支持 OpenStreetMap 及自定义瓦片
- **瓦片叠加层**：可为某张底图配置额外叠加层（如卫星底图叠加路网标注），支持多条，且不会遮挡轨迹线
- **标记点显示**：在地图上以标记点形式显示图片与视频位置
- **标记聚合**：基于 Supercluster 自动聚合邻近标记，缩放时带合并/分裂过渡动画；同位置多节点支持蜘蛛网展开
- **图片详情**：点击标记可查看图片详情抽屉
- **视角控制**：支持缩放、平移、俯仰角调节、定位到指定图片
- **纯图模式**：可隐藏侧边栏，全屏查看地图
- **坐标转换**：自动将 WGS84 坐标转换为 GCJ02 坐标，适配国内地图服务商

### 3. 图片分组

- **创建分组**：创建多个分组进行图片分类
- **分组着色**：每个分组可设置不同颜色
- **分组筛选**：按分组筛选显示地图上的图片标记
- **批量分组**：支持批量设置图片的分组
- **右键菜单**：通过右键菜单快速设置分组
- **分组可见性**：可控制分组的显示/隐藏

### 4. GPX 轨迹管理

- **上传轨迹**：从运动 App（Strava、Nike 等）上传 GPX 轨迹文件，限制 50MB
- **轨迹展示**：在地图上展示轨迹路线，标注起点和终点
- **显示在主地图**：可将指定轨迹固定显示在主地图上，点击查看详情、切换高亮，右键操作
- **轨迹着色**：自定义轨迹线的颜色
- **轨迹悬停卡片**：悬停显示轨迹名称、距离、总时长
- **轨迹统计详情**：
  - 总距离
  - 开始/结束时间
  - 移动时间和总时间
  - 平均移动速度和配速
  - 最低/最高海拔和累计爬升/下降
  - 最大速度
  - 平均心率、踏频、温度（如 GPX 中包含）
- **多轨迹支持**：同时在地图上显示多条轨迹
- **轨迹分组关联**：可将轨迹与图片分组关联
- **时区设置**：GPX 时间戳不带时区信息时，可按所选时区解释（已内置常用时区，覆盖 UTC-12:00 ~ UTC+14:00）

### 5. 轨迹视频

- **视频导入**：从本地选择视频导入，自动探测时长与拍摄时间（creation_time 优先，文件名时间兜底）
- **内嵌 GPS 独立视频**：视频自带 GPS 元数据时，作为独立标记显示在地图上
- **时间对齐关联**：通过"对齐视频"弹窗，把视频以色带形式拖拽/输入到轨迹时间线上，建立与 GPX 轨迹的关联
  - 支持**绝对对齐**（按视频绝对起止时刻）与**相对对齐**（全部早于轨迹起点时按间隔排布）两种自动分配
- **轨迹视频节点**：在轨迹线上按采样与距离抽稀生成视频节点，点击节点可弹出播放弹窗
- **视频播放**：基于 video.js 的自定义控制栏，支持播放/暂停、音量、进度、全屏、键盘快捷键
- **流式播放**：优先走本地 HTTP 流（支持 Range 断点续传，边下边播），不可用时回退分块读取
- **视频封面**：自动提取第一帧作为标记/列表封面
- **全景视频**：支持手动切换为全景视频，使用等距柱状投影沉浸式播放
- **视频分组与删除**：视频可加入分组、批量删除

### 6. 时间轴

- **时间筛选**：通过双滑块选择时间范围，实时筛选地图上的图片/视频（含聚合结果）
- **精度切换**：支持年 / 月 / 日三档时间精度
- **分布折线图**：以平滑面积线展示不同时间段的数据分布
- **重置**：一键恢复完整时间范围

### 7. 框选与批量操作

- **框选**：按住 `Ctrl`（macOS `Cmd`）+ 左键拖拽框选；按住修饰键为追加选中，否则替换；`Esc` 取消
- **选中预览**：顶部工具栏显示已选中节点数量
- **批量操作**：批量删除、批量加入分组、清空选中
- 分组节点不参与框选，聚合点会自动展开为其包含的全部图片/视频

### 8. 用户管理

- **多用户**：支持创建多个用户，每个用户有独立的数据空间
- **用户切换**：快速切换不同用户，查看各自的数据
- **用户删除**：删除用户及其所有数据（同时清理该用户的缓存）
- **用户头像**：支持设置用户头像
- **数据隔离**：每个用户的数据相互隔离，互不影响

### 9. 数据备份与恢复

- **创建备份**：一键将所有数据打包成 ZIP 备份文件，显示进度并支持中途取消
- **备份历史**：查看所有已创建的备份文件列表
- **数据恢复**：从备份文件恢复数据
- **导入模式**：
  - 覆盖模式：校验通过后替换现有数据（失败会保留原数据）
  - 合并模式：保留现有数据，按 ID 去重追加备份中的新数据
- **备份删除**：删除不需要的备份文件

### 10. 系统设置

- **语言切换**：支持中文、英文等多种语言
- **地图瓦片配置**：添加、编辑、删除自定义地图瓦片，可设置封面并配置叠加层
- **存储目录**：修改数据目录与备份目录
- **用户与数据管理**：用户增删、数据备份导入导出

## 数据存储

### 目录结构

```
D:\PicMap\
├── appSchema.json          # 应用配置文件（用户列表、地图瓦片配置等）
├── PicMap_Backup\          # 备份文件目录
│   └── PicMap_Backup_*.zip
└── [用户ID]\               # 每个用户的数据目录
    ├── images\
    │   ├── schema\
    │   │   └── schema.json # 用户图片标注数据
    │   ├── _THUMBNAIL_PM*.jpg  # 自动生成的缩略图
    │   └── PM*.jpg         # 用户上传的图片文件
    ├── tracks\             # GPX 轨迹文件
    ├── videos\             # 轨迹视频文件
    └── icons\              # 用户自定义图标
```

### 数据文件说明

| 文件/目录 | 说明 |
|-----------|------|
| appSchema.json | 应用级配置，包含用户列表、地图瓦片配置等 |
| [用户ID]/images/ | 用户上传的原始图片与缩略图 |
| [用户ID]/images/schema/schema.json | 用户的标注数据（imageInfo、groupInfo、trackInfo、videoInfo、mapInfo） |
| [用户ID]/tracks/ | 用户 GPX 轨迹文件 |
| [用户ID]/videos/ | 用户轨迹视频文件 |
| [用户ID]/icons/ | 用户自定义图标 |
| PicMap_Backup/ | 自动生成的备份文件存储目录 |

### 存储配置文件

所选存储目录记录在用户主目录的 `.picmap-config.json`（`C:\Users\<用户名>\.picmap-config.json`），用于跨启动记住数据目录与备份目录。

## 技术栈

### 前端

- **Vue 3**：渐进式前端框架
- **TypeScript**：类型安全的 JavaScript 超集
- **Vite**：新一代前端构建工具
- **MapLibre GL**：开源地图库（WebGL 矢量渲染）
- **Photo Sphere Viewer**：全景图片/视频查看
- **video.js**：视频播放器
- **Element Plus**：基于 Vue 3 的 UI 组件库
- **Pinia**：轻量级状态管理库
- **ExifReader**：图片 EXIF 信息解析
- **Supercluster**：标记聚合
- **vue-i18n**：国际化解决方案
- **lodash-es**：工具库

### 后端

- **Go + Wails v2**：桌面应用框架，前后端通过 Wails 绑定通信（无 HTTP 服务）
- **imaging / golang.org/x/image**：图片解码、缩放、缩略图生成
- **goexif**：EXIF 解析
- **archive/zip**：备份打包与恢复
- **本地 HTTP 媒体流服务**：仅监听 127.0.0.1，为视频/图片提供支持 Range 的流式访问
- **外部工具**：ImageMagick（HEIC 转码）、libraw（RAW 解码）、ffmpeg（视频探测/取帧），随程序分发（`dist/tools/`）

## 注意事项

- 💡 所有数据保存在本地，建议定期进行备份
- 📍 只有包含 EXIF GPS 信息的图片才能自动定位，无 GPS 图片需手动设置
- 📂 默认存储路径为 `D:\PicMap`（可在设置中修改）
- 🌐 除地图瓦片需要联网获取外，其他功能均可离线使用
- 👤 多用户数据相互隔离，删除用户会删除该用户所有数据
- 🛤️ GPX 轨迹会自动从 WGS84 坐标转换为 GCJ02 坐标，以适配国内地图服务商

## 常见问题

**Q: 上传的图片没有在地图上显示？**

A: 检查图片是否包含 GPS 信息，没有 GPS 信息的图片需要手动设置位置。

**Q: 如何备份数据？**

A: 进入设置页面，点击"创建备份"按钮，系统会生成 ZIP 备份文件。

**Q: 如何切换用户？**

A: 点击界面右上角的用户图标，选择或创建其他用户。

**Q: HEIC 格式图片无法显示？**

A: 系统会自动将 HEIC 转换为 JPEG 格式存储，如果转换失败请确保图片完整性。

**Q: 如何添加 GPX 轨迹？**

A: 进入轨迹管理面板，点击上传按钮选择 GPX 文件。上传后轨迹将显示在地图上。

**Q: 如何把视频关联到轨迹？**

A: 在轨迹上传/编辑界面使用"对齐视频"功能，将视频拖拽到轨迹时间线上，保存后即可在轨迹上看到视频节点。

**Q: 轨迹上没有显示视频节点？**

A: 确认视频已完成时间对齐并被关联到该轨迹，且轨迹处于显示状态。
